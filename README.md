# Coursework 1
Приложение для анализа банковских операций.

## Описание
Этот проект предоставляет приложение для анализа транзакций, которые находятся в Excel-файле. Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы.

## Требования к окружению
- Python >= 3.14
- Requests - для работы с внешними API
- Pytest - для тестирования
- Pytest-cov - для отчетов о покрытии тестами


## Структура проекта
- data/ - папка с Excel-файлом, хранящим транзакции 
- src/ - пакет с исходным кодом приложения (интерфейс главной страницы, сервисы для анализа и отчетов)
- tests/ - пакет с тестами
- logs/ - папка для сохранения логов 
- reports/ - папка для сохранения отчетов
- config.py - файл с переменными, в которых сохранены пути
- main.py - точка запуска


## Основной функционал
- Генерация JSON-данных для веб-страниц
- Анализ данных
- Формирование отчетов 

## Использование
- Введите дату в формате YYYY-MM-DD HH:MM:SS
- Введите год и месяц (без ведущего 0) для анализа категорий кэшбэка
- Введите название категории и дату для отчета о тратах по категории за последние три месяца

## Установка и запуск
1. Клонируйте репозиторий:
```
git clone https://github.com/NataKirp/coursework_1.git
```
2. Перейдите в папку проекта:
```
cd coursework_1
```
3. Активируйте виртуальное окружение через __Poetry__


4. Зависимости:

В случае отсутствия менеджера проектов __Poetry__, установите зависимости
из списка зависимостей в файле __pyproject.toml__

```
# Создание: 
pip freeze > requirements.txt

# Установка:
pip install -r requirements.txt
```

5. Запустите приложение из корневой папки проекта:
```
main.py
```

## Тестирование
Для запуска тестов используйте команду
``` 
poetry run pytest --cov 
```
Текущее покрытие кода составляет ~85%.
